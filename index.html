Для новых сотрудников команды 1С

Подготовка ИИ к работе с 1С

Вся настройка начинается отсюда. Ваш ИИ получит правила команды и навыки 1С, а база знаний окажется у вас на компьютере.

Начать настройку Скачать инструкцию (Word)

Один раз на компьютер, 30–60 минут. Большую часть делает сам ИИ, программировать не требуется.

Инструкция открыта всем, репозитории приватные.

Настройка по шагам

Номера шагов совпадают с инструкцией в Word.

Перед началом

Заведите аккаунт на GitHub и сообщите его имя руководителю. Он добавит вас в репозитории 1c-ai-kit и 1c-knowledge-team. Приглашение придёт на почту, его нужно принять. Ещё понадобятся компьютер с Windows и права на установку программ.

Какой у вас ИИ:

  1. Поставить свой ИИ

    Аккаунт на claude.ai с подпиской Pro или Max (Max, если работаете с ИИ весь день). Приложение с claude.ai/download, вход, вкладка Code слева.

    Приложение или терминальная версия OpenAI Codex, вход в свой аккаунт.

    Редактор с cursor.com, вход в свой аккаунт. Чат агента открывается клавишами Ctrl+L.

  2. Поставить Git и скачать набор

    Откройте PowerShell: меню «Пуск», введите PowerShell. Если Git ещё нет, выполните:

    winget install -e --id Git.Git

    Закройте окно PowerShell, откройте заново и скачайте набор:

    git clone https://github.com/elimarev/1c-ai-kit C:\workspace\1c-ai-kit

    При первом скачивании Git попросит войти в GitHub. Войдите в браузере под своим аккаунтом.

  3. Открыть папку набора в ИИ

    Вкладка Code, выбрать папку C:\workspace\1c-ai-kit.

    Открыть в приложении папку C:\workspace\1c-ai-kit как проект. В терминале: перейти в эту папку и запустить codex.

    File → Open Folder, папка C:\workspace\1c-ai-kit, затем новый чат (Ctrl+L).

    В списке файлов должны быть папки setup и claude. Настройку запускайте только отсюда, не из папки проекта.

  4. Попросить ИИ всё подготовить

    Напишите в чат одну фразу. Она одинаковая для всех трёх ИИ:

    Подготовь меня к работе с 1С

    ИИ проверит компьютер, задаст 2–3 вопроса и покажет план. Без вашего «да» ничего не ставится. Затем установит навыки и правила и выведет список того, что нужно сделать руками.

    Если ИИ спрашивает разрешение запустить install.ps1 или записать файлы в домашнюю папку, это нормально. Сверьте команду с планом и разрешите. Настройки безопасности самого ИИ менять не нужно.

  5. Подключить сервисы

    GitHub обязательно, Notion и Google Drive по необходимости: claude.ai → Настройки → Коннекторы.

    GitHub обязательно. Выполните команду; если gh нет, сначала winget install -e --id GitHub.cli:

    gh auth login

    Notion и Google Drive, если нужны для работы, подключаются в настройках самого ИИ.

    Подключения включаете вы сами: ИИ подскажет шаги, но пароли не вводит. Доступ давайте только к рабочему пространству команды, не к личным папкам.

  6. Базы 1С: только если работаете с ними на этом компьютере

    • 1c-mcp-bridge: метаданные и запросы, только чтение. Скачать 1cMcpBridge-Setup со страницы выпусков и запустить от администратора.
    • 1c-testpilot: открытие форм и сценарии в клиенте 1С. Его ставит сам ИИ, если вы ответите, что работаете с базами.

    Подключайте только тестовые копии баз. Пароли к базам не пишите в чат и в файлы.

    Поставили эти программы после основной настройки? Попросите ИИ: «Подключи установленные MCP».

  7. Проверить результат

    Перезапустите приложение ИИ, откройте ту же папку и вызовите проверку. Можно проще: написать «проверь окружение».

    /kit-check
    $kit-check

    Всё получилось, если в таблице проверки нет обязательных пунктов со статусом «нет», а ИИ может назвать правила команды о рабочих базах.

  8. Начать работу над проектом

    Каждый клиентский проект живёт в отдельном приватном репозитории. Новый проект заводит сам ИИ:

    /new-project
    $new-project

    Дальше открывайте в ИИ папку проекта, а не набора. Коллега с другим ИИ может работать в той же папке.

Правила, которые нельзя нарушать

Действуют с первого дня.

  1. Не подключать рабочие базы клиентов к ИИ и ничего в них не менять.
  2. Не проводить, не перепроводить и не удалять документы без разрешения, даже в тестовой копии.
  3. Не отправлять данные клиентов, выгрузки баз и пароли во внешние сервисы и чужие чаты.
  4. Репозитории проектов только приватные. Пароли и токены не хранить в репозиториях.
  5. В общую базу знаний только обезличенные случаи: без названий клиентов, людей, товаров и номеров документов.
  6. Если ИИ сказал, что что-то проверено, спросите, чем именно. Окончательно результат принимаете вы.

Если что-то пошло не так

Не получается за 15 минут? Напишите руководителю и приложите текст ошибки, но без паролей и данных клиентов.

git clone пишет Repository not found

Нет доступа. Примите приглашение GitHub на почте или попросите руководителя добавить вас.

Команда git не найдена

Закройте и снова откройте PowerShell. Не помогло: повторите установку Git из шага 2.

ИИ предлагает Docker, ffmpeg и другие посторонние программы

Вы не в папке набора или сработал другой навык. Откройте C:\workspace\1c-ai-kit в новом чате и напишите: «Прочитай claude/commands/onboard.md и выполни».

ИИ не понимает фразу или нет команды onboard

Напишите: «Прочитай claude/commands/onboard.md и выполни».

python открывает Microsoft Store

Выполните winget install -e --id Python.Python.3.12 и перезапустите приложение ИИ.

«Выполнение сценариев отключено»

Запускайте так, как предлагает ИИ: powershell -ExecutionPolicy Bypass -File .... Настройки Windows менять не нужно.

Ошибка доступа к .agents или .codex при установке

ИИ работает в защищённом режиме. Разрешите ему эту команду или запустите её сами в PowerShell: ИИ подскажет какую.

База знаний не скачалась

Нет доступа к 1c-knowledge-team. Попросите руководителя добавить вас и снова запустите настройку.

Не работает проверка BSL в Claude Code

Нужна Java 21: winget install -e --id EclipseAdoptium.Temurin.21.JDK.

Не видно инструментов базы 1С

Не поставлен 1c-mcp-bridge, см. шаг 6. В Claude Code и Codex при открытии проекта подтвердите доверие к нему.

Как обновлять

Когда руководитель сообщит о новой версии набора, выполните команду, затем откройте папку набора в ИИ и напишите «Обнови настройку».

git -C C:\workspace\1c-ai-kit pull

Файлы, которые вы меняли у себя, не затираются: ИИ покажет разницу и спросит.
